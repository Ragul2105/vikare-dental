5. Authentication Token Lifecycle
Tokens stored in flutter_secure_storage. Claims decoded client-side. Idle timer auto-expires sessions.

Token Flow — Step by Step

  • 1
    App Launch: restoreSession()Reads accessToken from SecureStorage. Decodes JWT claims client-side (base64 + JSON). Checks exp timestamp.
  • 2
    Access Token ValidUserProfile built from claims (sub, role, name). AuthState set to authenticated. Idle timer starts (10 min).
  • 3
    Access Token ExpiredrefreshSession() called. Uses publicApiClientProvider for POST /auth/refresh. On success → new tokens saved → session restored.
  • 4
    401 During API Call_AuthInterceptor catches it. Calls _refreshTokens(). On success, retries original request with new Bearer token. One retry per request only.
  • 5
    Refresh Also FailshandleSessionExpired() called → clears tokens → AuthState reset → GoRouter redirects to /login with message.
  • 6
    Idle TimeoutTimer(10 min) fires → handleSessionExpired() → "Logged out due to inactivity." User shown login screen.

9. Key Architectural Decisions
Design choices that define scalability, maintainability, and developer experience

Riverpod — Not BLoC/Provider

StateNotifier for auth state machine. Provider for Dio clients and Repositories. FutureProvider.family for parameterised async data. No boilerplate streams.

Sealed ApiResponse<T>

All HTTP results wrapped in ApiSuccess / ApiFailure. .when() pattern forces error handling at callsite. No uncaught exceptions bubble to UI.

Photo Compression Pipeline

flutter_image_compress reduces photos to 85% JPEG quality before upload. Saves bandwidth and S3 storage. Processed in VisitRepository.uploadPhotos().

GoRouter Auth Redirect

appRouterProvider watches authControllerProvider. On any auth state change, GoRouter re-evaluates redirect(). No manual navigation calls needed.

Hive for Offline Cache

Master data (treatments, medications) cached in Hive Box<String>. Initialised at app startup. Prevents repeated network calls for static dropdown data.

Two Dio Clients

publicApiClientProvider (no auth interceptors) used for login and token refresh to prevent circular refresh loops. apiClientProvider used for all authenticated calls.
