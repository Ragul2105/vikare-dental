1. Layered Architecture Overview
The backend is built in a strict 4-layer pattern: Routing → Services → Models → Database

Figure 1 — Request passes through Middleware stack → Router → Service → Database. All layers communicate via FastAPI dependency injection.

2. Request Lifecycle & Data Flow
Every authenticated API call follows this precise lifecycle from network entry to response

Inbound Request Flow

  • 1
    CORS & Rate Limit Check200 req/min per IP enforced by SlowAPI. CORS origins validated from env config.
  • 2
    Request ID AssignedRequestLoggingMiddleware attaches a UUID to request.state.request_id for tracing.
  • 3
    JWT Verification (get_current_user)Bearer token decoded → user UUID extracted → User fetched from DB → stored in request.state.
  • 4
    Role Guard (require_role)require_admin / require_any_staff composables check role on the resolved User object.
  • 5
    Pydantic Schema ValidationRequest body is automatically validated against the Pydantic BaseModel schema. Returns 422 on failure.
  • 6
    Service Layer ExecutionRouter delegates to a Service instance, passing AsyncSession (get_db). Business logic runs here.
  • 7
    DB Commit / Rollbackget_db() commits on success or rolls back on any exception before yielding.
  • 8
    Activity Log (background)ActivityLoggerMiddleware attaches a BackgroundTask to log POST/PATCH/DELETE to activity_logs after response is sent.

Dependency Injection Graph

Router endpoint
  └─ get_db() → AsyncSession
  └─ get_current_user()
     ├─ HTTPBearer credentials
     ├─ decode_token()
     └─ db.get(User, id)
  └─ require_role("admin")
     └─ wraps get_current_user
  └─ ServiceClass(db)
     └─ business logic
     └─ selectinload(relations)

Services receive the AsyncSession injected from the router. Each service is instantiated fresh per request — no shared state.

Error Response Contract

{
  "error_code": "VALIDATION_ERROR",
  "message": "Human-readable text",
  "details": { ...context }
}

4. Authentication & Authorization Flow
PIN-based login, dual JWT tokens (access + refresh), role-based guards

Figure 3 — Authentication flow. Login validates PIN via bcrypt. Two JWT tokens minted. Refresh path uses the 7-day refresh token. Idle auto-logout enforced on Flutter side.

5. File Storage Strategy
Dual-backend abstracted by S3Service — switchable via FILE_STORAGE_BACKEND env var

📦 Local File System Mode

  • Files written to data/storage/
  • FastAPI serves via StaticFiles mount
  • URL: /api/v1/assets/{key}
  • Path traversal blocked in _local_path_for_key()
  • Auto-creates directories on startup

☁️ AWS S3 Mode

  • boto3 client, region: ap-south-1
  • Server-side encryption: AES256
  • Presigned URLs expire in 900 seconds (15 min)
  • Used for visit photos & prescription PDFs
  • Key format: visits/{id}/photos/...

Figure 4 — File storage abstraction. Same S3Service interface works for both backends. Only the env var switches the implementation.

8. Key Architectural Decisions
Design choices that define the shape and maintainability of the system

Async-First

  • asyncpg driver for PostgreSQL
  • SQLAlchemy 2.0 async sessions
  • httpx async client for WATI
  • No blocking I/O in hot paths

Pydantic v2 Schemas

  • Input validation fully declarative
  • Schemas separate from ORM models
  • response_model drives serialisation
  • Strict field validators on Settings

Soft Delete Pattern

  • Patients never hard-deleted
  • is_deleted + deleted_at + reason
  • All queries filter is_deleted=False
  • Audit trail preserved in activity_logs

Inventory as Addon

  • INVENTORY_ADDON_ENABLED env flag
  • Router dynamically included at startup
  • Feature isolation without separate service

Selectinload Strategy

  • Explicit eager loading via selectinload()
  • Avoids N+1 query problem
  • Relations loaded in separate SELECT
  • Consistent response shape for Flutter

Standardised Errors

  • All errors: {error_code, message, details}
  • Centralised exception handlers in main.py
  • Custom error codes (VALIDATION_ERROR etc.)
  • Flutter maps them to AppError objects
